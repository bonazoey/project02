# 회원 가입·로그인·정보 관리

프로젝트 공통 규칙은 [AGENTS.md](../../../AGENTS.md)를 따른다.

## 구현 절차

1. 가입·로그인·조회·수정·탈퇴 DTO와 member 스키마를 확인한다. 원본 필드는 mid, mname, mpassword, memail, menabled, mrole이다.
2. 가입 입력을 검증하고 BCrypt 해시를 저장한다. 역할·활성 상태는 서버가 정한다. DB 고유 제약으로 동시 중복 가입도 처리한다.
3. 아이디로 조회한 해시와 matches로 비교한다. 입력을 재해시해 문자열 비교하지 않는다. 비활성 계정 정책을 적용한다.
4. 성공한 인증 결과로만 토큰 발급을 호출한다. success/wrong-mid/wrong-mpassword는 참고 계약이며 신규 오류·상태 코드는 일관되게 정한다.
5. 조회·수정·탈퇴는 인증 사용자와 대상 접근 권한을 확인한다. 요청 mid만 믿지 않고 일반 입력으로 역할·활성 상태를 바꾸지 못하게 한다.
6. 비밀번호 변경이 요청된 때만 해시하며 미입력 수정은 보존한다. 미존재 회원과 영향 행 수 0을 처리한다.
7. 응답에서 비밀번호·해시를 제외하고 전체 DTO·토큰을 로그에 남기지 않는다.

## 검증

가입 성공·중복·해시 저장, 정상/실패/비활성 로그인, 비밀번호 미변경 수정, 타인 변경 차단, 삭제 후 조회를 확인한다. 실패 시 토큰이 발급되지 않는지 검사한다.

## 포함된 예제 소스

이 SKILL의 `assets/source/java/`에 Java 예제와 관련 타입을 포함했다. XML·HTML이 필요한 기능에는 `assets/source/resources/`도 포함했다. [포함 파일 목록](references/source-notes.md#포함된-소스)에서 필요한 파일만 읽는다. 외부 back-end-spring-boot 프로젝트 경로를 찾을 필요가 없다. 원본 사본이므로 아래 참고 문서의 차이점과 이 SKILL의 구현 지침에 맞춰 적용하며, 그대로 실행 가능한 현재 프로젝트 코드로 간주하지 않는다.
