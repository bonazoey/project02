# 게시판 CRUD

프로젝트 공통 규칙은 [AGENTS.md](../../../AGENTS.md)를 따른다.

## 구현 절차

1. 식별자·제목·본문·작성자·작성일·조회수·첨부 여부와 기존 URL을 확인한다. /database/board를 신규 경로로 강제하지 않는다.
2. 등록/수정 요청과 목록/상세/등록/수정 응답 DTO를 구분한다. 요청을 엔티티로 변환해 서비스에 위임한다.
3. 작성자는 기존 인증 방식으로 확인된 사용자에서 얻고 작성일·생성 키는 서버/DB에서 결정한다. 작성자 입력 조작을 허용하지 않는다.
4. insert 후 생성 키로 조회한다. 상세·수정·삭제는 존재 여부를 확인하고 수정/삭제는 소유자 또는 허용 역할을 검사한다.
5. update/delete 0건은 성공으로 처리하지 않는다. 함께 처리할 DB 변경은 서비스 트랜잭션으로 묶는다.
6. 미첨부 수정은 기존 첨부를 유지하고 새 파일·명시적 삭제를 구별한다. 목록에 본문 전체나 첨부 바이트를 싣지 않는다.
7. 조회수 증가가 요구되면 원자 증가 SQL과 호출 시점을 정한다. 원본 getBoard()에 증가가 구현되어 있다고 가정하지 않는다.

## 검증

등록→조회→수정→삭제, 미존재 ID, 타인 수정·삭제, 첨부 보존, 복합 변경 실패를 확인한다. 원본 DTO 이름은 참고하고 현재 명명 관례를 따른다.

## 포함된 예제 소스

이 SKILL의 `assets/source/java/`에 Java 예제와 관련 타입을 포함했다. XML·HTML이 필요한 기능에는 `assets/source/resources/`도 포함했다. [포함 파일 목록](references/source-notes.md#포함된-소스)에서 필요한 파일만 읽는다. 외부 back-end-spring-boot 프로젝트 경로를 찾을 필요가 없다. 원본 사본이므로 아래 참고 문서의 차이점과 이 SKILL의 구현 지침에 맞춰 적용하며, 그대로 실행 가능한 현재 프로젝트 코드로 간주하지 않는다.
